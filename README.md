## 📌 Sobre o Projeto

O **Moon Study** é uma aplicação web desenvolvida para auxiliar estudantes na organização de sua rotina de estudos.

O sistema permite cadastrar estudos, definir datas e horários, acompanhar atividades concluídas e visualizar o progresso.

---

## 🎯 Objetivo

O objetivo do projeto é criar uma ferramenta simples e prática para ajudar estudantes a:

* Organizar sua rotina;
* Planejar seus horários;
* Controlar suas atividades;
* Acompanhar seu progresso;
* Melhorar sua organização nos estudos.

---

## 💡 Problema

Muitos estudantes possuem dificuldade para organizar seus estudos e acabam esquecendo tarefas, datas e horários.

Pensando nisso, a equipe **Moon Tech** desenvolveu o **Moon Study**, uma solução digital para facilitar esse planejamento.

---

## 🚀 Funcionalidades

### 📅 Calendário

Permite visualizar os dias do mês e identificar os dias que possuem estudos cadastrados.

### 📚 Cadastro de Estudos

O usuário pode cadastrar:

* Matéria;
* Data;
* Horário;
* Assunto.

### ✅ Controle de Estudos

É possível marcar uma atividade como **concluída** ou **pendente**.

### 🗑️ Exclusão

O usuário pode excluir estudos que não são mais necessários.

### 📊 Progresso

O sistema calcula automaticamente:

* Total de estudos;
* Estudos concluídos;
* Estudos pendentes;
* Porcentagem de progresso.

## 📖 Como Utilizar

1. Acesse o **Moon Study**.
2. Vá até a área de estudos.
3. Informe a matéria.
4. Escolha a data.
5. Informe o horário.
6. Digite o assunto.
7. Clique em **Salvar estudo**.
8. Após realizar a atividade, clique em **Concluir**.
9. Acompanhe seu progresso no painel.
